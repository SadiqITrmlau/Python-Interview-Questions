## 💻 A Little Python Motivation

```python
class FutureDeveloper:

    def __init__(self):
        self.skills = ["Python", "Problem Solving"]
        self.confidence = 0

    def practice(self):
        self.confidence += 1
        print("Learning something new!")

    def success(self):
        while self.confidence < 100:
            self.practice()

        print("Interview Cracked! 🚀")


developer = FutureDeveloper()
developer.success()
```
